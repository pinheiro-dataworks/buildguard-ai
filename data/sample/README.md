# Sample Data

Small, deterministic samples of the synthetic BuildGuard AI dataset, generated
by `make data` (`scripts/generate_data.py` → `src/buildguard/data/synthetic.py`),
committed here so the repository is runnable without a generation step for
quick inspection (e.g. in `notebooks/`). The full dataset used for
training/evaluation is regenerated on demand, not committed.

Nothing has been generated yet — the synthetic data generator lands in
Phase 1 (Data Foundation).
